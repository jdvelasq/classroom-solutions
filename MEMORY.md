# CLASSROOM Memory

This repository is the persistent source of truth for the CLASSROOM project.

ChatGPT, Work, Claude Code, Codex, Gemini and Copilot conversations are working contexts, not the canonical project memory.

## Reading order

For global work, read:

1. `PROJECT.md`
2. `design/synthesis.md`
3. `AGENTS.md`

For work on a specific course, then read:

4. `<course>/COURSE.md`
5. `<course>/decisions.md`
6. `<course>/pre-catalog.md`
7. `<course>/schedule.md`

## Source precedence

When information conflicts, use this order:

1. `<course>/decisions.md`
2. `<course>/COURSE.md`
3. `design/synthesis.md`
4. `curriculum/`
5. existing implementations
6. chat history

## Persistence rule

Important decisions reached during a working session must be written back to the appropriate repository document.

Do not use this file to store course content, schedules, design decisions or conversation summaries.
