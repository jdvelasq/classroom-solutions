# Currículo macro — Fundamentos de Datos para Analítica

## Rol en el programa

Curso de ingeniería de datos para consumo analítico. Responde cómo transformar fuentes heterogéneas en datos confiables, reproducibles, documentados y disponibles. No es administración de bases de datos, certificación de herramientas ni desarrollo del producto analítico final.

La secuencia siguiente es conceptual, no un calendario ni una asignación de duración.

En la programación detallada, una sesión puede incluir varios `PRE_*` autocontenidos cuando su complejidad y progresión pedagógica lo permitan.

## Unidades

### 1. Datos en el ciclo analítico

Productores y consumidores de datos, ciclo de vida, arquitectura, confiabilidad, escalabilidad, costo y relación entre ingeniería de datos, analítica y productos de datos.

### 2. Representación relacional y SQL para analítica

Tablas, claves, relaciones, integridad, esquemas y SQL como lenguaje de integración y transformación. Nivelación suficiente para estudiantes con trayectorias previas distintas.

### 3. Integración y transformación reproducible

Joins, agregaciones, ventanas, deduplicación, tipado, faltantes, transformaciones declarativas y capas raw/staging/curated.

### 4. Modelado y almacenamiento analítico

OLTP/OLAP, hechos, dimensiones, data marts, warehouses, lagos y lakehouses. Selección de estructura por patrón de consumo analítico, no por moda tecnológica.

### 5. Formatos, esquemas y datos semiestructurados

CSV, JSON, Parquet, tipos, compresión, particionamiento, evolución de esquema y criterios para combinar representación relacional, documentos y almacenamiento de objetos.

### 6. Ingestión de fuentes

Ingestión por lote, bases de datos, APIs y eventos: extracción, paginación, parámetros, persistencia, reintentos, errores e idempotencia.

### 7. Pipelines y procesamiento incremental

ETL/ELT, dependencias, configuración, ejecución incremental, append/upsert, backfill, orquestación y trazabilidad de transformaciones.

### 8. Calidad de datos y contratos

Completitud, validez, unicidad, consistencia y frescura; pruebas, contratos, evolución, cuarentena y fallos controlados.

### 9. Escala, eventos y streaming

Límites del procesamiento local, particiones, cómputo distribuido, eventos, tiempo de evento, ventanas y flujos continuos como decisiones arquitectónicas.

### 10. Serving, metadatos y gobierno técnico

Datos curados para consumidores, catálogos, linaje, semántica, propiedad, acceso, privacidad y seguridad técnica.

### 11. Arquitectura integral de datos para analítica

Diagnóstico de una arquitectura extremo a extremo, trade-offs y diseño de una mejora que entregue datos confiables a Descriptiva, Predictiva, Prescriptiva y Productos.

## Frontera curricular

Este curso diseña y produce datos confiables. Productos de Datos opera una capacidad analítica para un consumidor; los cursos de analítica usan los datos para describir, anticipar o decidir.
